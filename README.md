# dictionary-demo

Data dictionary and documentation for the AHEAD database (PostgreSQL/PostGIS).

## About the project

This dictionary has been developed for the [AHEAD project](https://www.dabc.polimi.it/en/research-projects/ahead) ("Advanced disaster damage and loss data information system for enHancEd impAct-baseD knowledge"), led by the Department of Architecture, Built Environment and Construction Engineering (DABC) at Politecnico di Milano. The project is funded by the European Commission under the programme "Knowledge for Action in Prevention and Preparedness".

The dictionary describes the tables and attributes of the database as they are implemented in PostgreSQL.

## Languages

The site is available in English, Italian, French, Portuguese and German. The English version is the reference. The translations were produced with AI assistance and may contain errors. Table and attribute names are identical in all languages because they match the PostgreSQL implementation.

## Build

The site is built with MkDocs Material and published on GitHub Pages by the workflow in `.github/workflows/ci.yml`.
