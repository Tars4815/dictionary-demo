# Willkommen im Datenwörterbuch-Hub

!!! warning "KI-gestützte Übersetzung"

Willkommen auf der zentralen Dokumentationsplattform für die Datenbank unseres Projekts. 

Diese Plattform soll unsere Datenstruktur für alle Projektbeteiligten transparent, zugänglich und leicht verständlich machen, ob Entwicklerin, Datenanalyst oder Fachexperte.

---

## Unsere Ziele

Die wichtigsten Ziele dieses Datenwörterbuchs sind:

* **Einheitliche Wissensgrundlage:** Eine verlässliche, standardisierte Referenz für alle Datenbankentitäten, ihre Attribute und ihre Beziehungen bereitzustellen.
* **Zugänglichkeit:** Eine einfache, schnelle und leicht teilbare Weboberfläche anzubieten. Für das Verständnis unserer Daten sind weder aufwendige Softwareinstallationen noch Datenbank-Zugangsdaten erforderlich.
* **Klarheit und Kontext:** Über die reinen „Datentypen“ hinauszugehen. Hier finden Sie fachliche Definitionen, Einschränkungen, Beispielwerte und spezifische Regeln (z. B. zum Umgang mit Geodaten) für jede einzelne Spalte.
* **Gemeinsame Pflege:** Auch Teammitglieder ohne technischen Hintergrund zu befähigen, die Dokumentation über einen vereinfachten Arbeitsablauf aktuell zu halten.

## So navigieren Sie

Die gesuchten Informationen finden Sie schnell und einfach:

1. **Suchleiste:** Nutzen Sie die leistungsstarke Suchleiste oben auf der Seite. Sie durchsucht sofort Tabellennamen, Spaltendefinitionen und Kommentare.
2. **Interaktives Schema:** Beginnen Sie mit der [Schemaübersicht (ER)](schema_er.md), um einen Überblick darüber zu erhalten, wie die verschiedenen Tabellen zueinander in Beziehung stehen.
3. **Tabellendetails:** Nutzen Sie das Navigationsmenü an der Seite, um sich in bestimmte Bereiche und Tabellen zu vertiefen. Jede Seite bietet eine ausführliche Beschreibung der ausgewählten Tabelle.

## So können Sie mitwirken

Dokumentation ist nur nützlich, wenn sie aktuell bleibt. Wir haben diese Plattform so aufgebaut, dass **jede und jeder mitwirken kann, ganz ohne Programmierung**.

!!! info "Das Wörterbuch über Excel aktualisieren"

    Sie müssen weder Markdown noch Git kennen, um zu helfen! Aktualisierungen verwalten wir über eine einfache **Excel-Vorlage**. 
    
    Wenn Sie eine neue Tabelle definieren oder eine bestehende Beschreibung aktualisieren möchten, genügt es, eine Tabellenkalkulation mit Spalten wie *Data type, Definition, Example value usw.* auszufüllen. 
    
    Das technische Team wandelt Ihr Excel-Blatt automatisch in diese Webseiten um. Weitere Einzelheiten finden Sie in den [Hinweisen zur Mitarbeit](guidelines.md).
