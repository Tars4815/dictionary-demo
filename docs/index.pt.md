Bem-vindo à plataforma central de documentação da base de dados do nosso projeto. 

Esta plataforma foi concebida para tornar a estrutura dos nossos dados transparente, acessível e fácil de compreender para todas as pessoas envolvidas no projeto, sejam programadores, analistas de dados ou especialistas na matéria.

---

## Os nossos objetivos

Os principais objetivos deste dicionário de dados são:

* **Fonte única de verdade:** Fornecer uma referência fiável e normalizada para todas as entidades da base de dados, os seus atributos e as suas relações.
* **Acessibilidade:** Oferecer uma interface web simples, rápida e fácil de partilhar. Não são necessárias instalações de software complexas nem credenciais da base de dados para compreender os nossos dados.
* **Clareza e contexto:** Ir além dos simples “tipos de dados”. Aqui encontra definições de negócio, restrições, exemplos de valores e regras específicas (p. ex. o tratamento de dados geográficos) para cada coluna.
* **Manutenção colaborativa:** Permitir que os membros da equipa não técnicos mantenham a documentação viva e atualizada através de um fluxo de trabalho simplificado.

## Como navegar

Encontrar a informação de que precisa é rápido e simples:

1. **Barra de pesquisa:** Utilize a poderosa barra de pesquisa no topo da página. Pesquisa instantaneamente nos nomes das tabelas, nas definições das colunas e nos comentários.
2. **Esquema interativo:** Comece pela [visão geral do esquema (ER)](schema_er.md) para ter uma perspetiva global de como as diferentes tabelas se relacionam entre si.
3. **Detalhes das tabelas:** Explore o menu de navegação lateral para aprofundar domínios e tabelas específicos. Cada página apresenta uma descrição exaustiva da tabela selecionada.

## Como contribuir

A documentação só é útil se se mantiver atualizada. Construímos esta plataforma para que **qualquer pessoa possa contribuir, sem necessidade de escrever código**.

!!! info "Atualizar o dicionário através do Excel"

    Não precisa de saber Markdown nem Git para ajudar! Gerimos as atualizações através de um simples **modelo Excel**. 
    
    Se precisar de definir uma nova tabela ou de atualizar uma descrição existente, basta preencher uma folha de cálculo com colunas como *Data type, Definition, Example value, etc.* 
    
    A equipa técnica converterá automaticamente a sua folha Excel nestas páginas web. Leia as [diretrizes de contribuição](guidelines.md) para mais detalhes.
